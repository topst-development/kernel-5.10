Telechips reboot mode driver

This driver gets reboot mode magic value from reboot-mode driver and store it in
PMU (Power Management Unit) via related SiP service call or directly if the call
call is not supported. Then the bootloader can read it and take different action
according to the magic value stored.

Required properties:
- compatible: Should be "telechips,reboot-mode"
- mode-xxx: Magic value for xxx reboot mode.  Refer to reboot-mode.txt.

Optional properties:
- reg: Address and size of PMU register to store reboot mode magic.
- record-init: Magic value for initial value to set on device probe.
- record-panic: Magic value for kernel panic.

Example:
	reboot-mode {
		compatible = "telechips,reboot-mode";
		mode-normal = <BOOT_NORMAL>;
		mode-bootloader = <BOOT_FASTBOOT>;
		mode-recovery = <BOOT_RECOVERY>;
		record-panic = <BOOT_PANIC>;
	};
