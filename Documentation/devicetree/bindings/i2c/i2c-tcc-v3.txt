Device tree configuration for Telechips I2C Master Controller Version 3

Required properties:
- compatible	: Name for matching with the drivevrs depending on chipset
		Should be
		"telechips,tcc805x-i2c-v3"
		"telechips,tcc803x-i2c-v3"
		"telechips,tcc750x-i2c-v3"
		"telechips,tcc807x-i2c-v3"
- reg		: Physical base address and size of the controller's register area.
- interrupts	: Interrupt specifier.
- clocks	: phandle to input clock.
- #address-cells: Should be 1.
- #size-cells	: Should be 0.
- pinctrl-names	: Should be "default"
- pinctrl-0	: phandle to pinctrl function
- port-mux	: Port number to set i2c output pin in tcc803x, tcc805x
- port-mfio     : Port to set i2c output to mfio gpio on tcc750x

Optional properties:
- peri-clock-frequency	: Desired I2C peripheral frequency in Hz, default is 4MHz.
- clock-frequency	: Desired I2C bus frequency in Hz, default is 100kHz.
- noise_filter		: Desired I2C Noise filtering time in ns, default is 50ns
- status		: Activation status
- ack-timeout		: If I2C receive NAK, i2c driver send the device address and check whether receiving ACK/NAK
			  It works repeatedly during "ack-timeout" count
			  the maximum value of "ack-timeout" is 1000
- xfer-timeout		: Maximum time[msec] the i2c controller can be used, default is 500 ms
- retry-count		: If I2C receive NAK, i2c driver sending a message retry count
- burst-mode 		: High-speed mode to reduce delay
- pulse-width-high	: Clock High Width
- pulse-width-low	: Clock Low Width
- cmd-timeout		: If not receive i2c command while cmd-timout, re-send command

Note:
GPIO used for I2C SCL/SDA are named as number. you can find port number in Chip Specification.
I2C bus frequency is generated from I2C peripheral frequency which is divided by prescale.
If i2c transfer between irqsave function, you should set interrupt_mode to 0.

Examples:
	i2c0: i2c@16300000 {
		reg = <0x16300000 0x1c 0x163c0000 0x10 0x16340004 0x04>;
		compatible = "telechips,tcc803x-i2c-v3";
		interrupts = <GIC_SPI 61 IRQ_TYPE_LEVEL_HIGH>;
		clocks = <&clk_peri PERI_I2C0 &clk_io IOBUS_I2C_M0 &clk_fbus FBUS_IO>;
		#address-cells = <1>;
		#size-cells = <0>;

		pinctrl-names = "default";
		pinctrl-0 = <&i2c11_bus>;
		port-mux = <11>;
		clock-frequency = <400000>;
		status = "okay";
		xfer-timeout = <1000>;

		dummy@60 {
			compatible = "dummy";
			reg = <0x60>;
		};
	};
